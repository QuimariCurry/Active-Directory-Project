# Active-Directory-Project

## Overview
* This repo contains my Active Directory detection lab where I used Windows Server, Windows 11, Sysmon, Splunk, Kali Linux, and Atomic Red Team. This project shows adversary simulation, log ingestion, detection analysis, and offensive testing.

## Highlights
* Built AD domain with users and groups
* Installed Sysmon and Splunk Universal Forwarder
* Configured Splunk on Ubuntu Server to ingest Windows logs
* Ran Atomic Red Team tests
* Performed RDP authentication attempts from Kali
* Analyzed events in Splunk to understand detection opportunities
